# Bien Hoo — app Android

Versões publicadas do app **Bien Hoo** (gestão da academia).

- **Instalar:** baixe o `.apk` do [release mais recente](../../releases/latest) e abra no celular.
- **Atualizar:** o app procura versões novas sozinho e se atualiza a partir daqui.

Este repositório contém só os pacotes gerados automaticamente. Não renomeie nem apague:
os apps instalados dependem deste endereço para receber atualizações.
